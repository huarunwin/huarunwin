# 客户端隐私说明

最后更新：2026-10-23

本说明适用于华润赢客户端本身。客户端访问的网站、GitHub、应用商店、Telegram 以及其他外部链接各自适用其服务方的隐私政策；客户端不会替这些服务方作出承诺。

## 客户端不主动收集的内容

客户端没有账号系统、广告标识、内置分析统计、崩溃上报或后台画像功能。客户端不会把浏览、搜索、下载和安装记录上传到项目服务器。公开源码供审计，但不代表所有外部网站或系统服务都不会记录访问信息。

## 网络请求

客户端可能请求以下地址：

- 浏览目录时按“内容来源”设置从 `huarun.win`、`raw.githubusercontent.com/huarunwin/huarunwin-static/main/` 或 `cdn.jsdelivr.net/gh/huarunwin/huarunwin-static@main/` 获取公开 HTML 和站内图片，更新排序或本机应用版本检查时按需获取相关详情 HTML；自动模式在网络失败时可能依次尝试三个来源，外部图片仍由原服务提供；
- 启动时自动从公开仓库 `huarunwin-hub` 检查客户端更新，设置中的手动检查、查看或刷新更新日志也会请求该来源；
- 用户选择的 GitHub Release 页面、附件或应用官方渠道；
- 按独立的“GitHub 加速”设置，通过 `gh-proxy.com` 转发公开 GitHub Raw 文本、GitHub 内容镜像的站内图片及应用内文件下载；默认自动模式在直连失败后可能使用该服务，目录／更新信息与文件下载分别保持回退线路 2 小时。镜像图片跟随 Raw 线路并允许单张图片回退，不改变全局保持时间；官网、jsDelivr 和外部图片不经过该代理，GitHub 版本列表继续直连；
- 用户主动打开的其他网站、系统浏览器、应用商店和 Telegram 链接。

这些服务通常能够看到标准网络请求信息，例如 IP 地址、时间、请求地址和 User-Agent。详情与安装包请求可能使服务方推知用户关注或已安装的应用，但客户端不会上传本机应用清单或下载历史文件。

纠错页面以及用户在 Android 机场、VPS 目录或详情中主动打开的购买／访问网站页面在应用内 WebView 中运行网站脚本；其后在网页内继续访问的页面也由 WebView 加载，可能使用网站 Cookie、登录会话及用户填写并提交的信息。这些内容由 WebView 和网站处理，不属于客户端目录解析缓存；网站可能提供自己的账号功能，本说明中的“没有账号系统”仅指客户端本身。

## 保存在本机的数据

客户端可能在本机保存：

- HTML、图片和解析后的目录缓存；
- 主题、筛选、更新提醒、下载目录、所选内容来源、GitHub 加速方式、各类请求最近成功的线路及回退保持期起算时间等偏好；
- 下载任务、安装状态、文件路径、校验摘要、本地安装结果及历史恢复备份；下载续传的半成品与原始及实际传输 URL、长度、ETag／Last-Modified 等校验记录；
- 受管理 APK 的实际包名、应用名称、版本和证书摘要，用于应用库归组和逐份核对；
- 用户主动下载或导入的安装包及其派生文件；
- Android 用户确认创建的 APK 签名密钥。可导出的备份由用户通过系统文件选择器自行保存。

缓存、偏好和下载记录保存在系统为应用提供的本地目录。下载文件保存在用户选择的受管理目录；修改目录不会自动搬迁旧文件。删除下载记录会按应用内提示清理相应的受管理文件，不卸载已安装应用。卸载应用或清除应用数据由操作系统决定，也可能一并删除本机记录和不可恢复的密钥。

系统或用户启用的设备备份可能包含偏好和历史记录，具体取决于平台、系统及备份设置。Android 可导出私钥通过 Android Keystore 中的 AES-GCM 密钥加密，密文存放于不参与系统自动备份的专用目录；旧版不可导出的 Keystore 密钥也不能靠普通备份恢复。客户端不保存备份密码。通过系统文件选择器导出的备份离开应用后由用户和所选存储服务负责保管；换机或清除数据前需要单独保管并确认密钥备份可用。

## 本机应用与文件检查

为显示“打开”“更新”和应用库状态，客户端会在进入页面、刷新或重新激活时检查本机应用及受管理文件，无需每次点击单独检查按钮。Android 查询已知包名及当前用户可见、可启动应用的名称、包名和版本，不申请系统全量应用查询权限；macOS 读取系统及用户应用目录顶层应用包的名称、标识和版本；Windows 读取当前用户及本机的系统卸载注册项，包括显示名称、版本和卸载身份；Linux 检查已记录的 AppImage，并读取当前发行版的软件包数据库。结果在本机内存中用于身份匹配与版本比较，不上传完整清单，不把打开安装器作为安装成功证明。iOS 不查询其他应用的完整安装清单。

## 权限与平台交接

Android 使用网络权限获取公开内容，并在用户确认安装 APK 时交给系统或用户选择的安装器；客户端不会静默安装、自动卸载应用或替用户授予“允许此来源安装应用”。用户选择导入文件时，客户端读取该文件并复制到受管理目录；安装器和分享接收方会获得用户选择的文件。桌面安装、打开应用、商店及浏览器交接按用户操作执行，所用系统工具和第三方服务遵循其各自规则。

Android 应用管理的“卸载应用”仅在用户明确选择已安装身份并确认后，使用 `REQUEST_DELETE_PACKAGES` 打开所选实际包名的系统卸载确认界面，由系统决定是否执行。此权限不授予静默卸载能力，客户端不申请 `DELETE_PACKAGES` 或全量包查询权限。卸载可能清除目标应用的数据；APK 和下载记录仍保留在华润赢中，系统界面返回后重新核对安装状态，不上传卸载请求或结果。

桌面卸载仅在用户选定具体应用并确认后执行。macOS 将经身份复核的应用包移到废纸篓；已启用受限管理员助手时直接复用，未启用时先尝试普通权限，权限不足后首次启用需用户另行确认并由系统管理员授权，之后跨操作与重启复用。助手每次复核目标后移到原用户的废纸篓，不读取或保存密码，不永久删除或改变应用权限。助手只核对废纸篓目录属性并移动选定应用，不读取其中的其他内容；若移动仍被 App 管理权限拒绝，可由用户打开系统设置并自行授权，返回后重新确认卸载。Linux 将受管理的 AppImage 移到系统回收站，两者均不自动清理应用外的设置和数据。Windows 使用所选注册项的交互卸载程序或系统应用管理，Linux 发行版软件包使用系统终端与包管理器，保留系统授权及依赖确认，不保存管理员密码、不自动同意包管理器提出的依赖变更。系统卸载程序自行决定目标应用数据的处理方式；下载文件和记录保留。iOS 仅展示系统操作指引。卸载身份和结果不上传。

macOS 仅在安装、卸载或客户端更新实际需要权限时首次申请管理员授权，此后持续复用，重启后保留，不提供独立管理页或预先启用入口。管理员助手以 root 所有的 launchd／XPC 服务保存在系统目录，按需响应经过代码签名和用户校验的客户端，只执行受限安装、移到废纸篓及客户端更新操作；不联网或自行扫描应用。配置保存获授权的本机用户和代码签名要求，不保存密码。可在 macOS 系统设置的“登录项与扩展”关闭华润赢的后台运行；关闭后台运行或仅删除客户端应用包不自动移除服务文件及授权配置。客户端内更新可迁移客户端信任，手动换签名或升级助手代码可能需在操作中重新确认系统授权。App 管理等系统隐私权限仍独立处理。

主动点击详情页的分享按钮时，客户端将当前页面标题和完整网页链接交给系统分享面板，由用户选择接收方及后续操作；系统和所选服务可能按自身规则处理这些内容。客户端不会随之附带下载历史、本机应用清单或安装包。取消分享不会自动发送或复制链接；系统分享不可用时，仅在用户选择“复制链接”后写入剪贴板。

Android 用户主动下载后使用 `FOREGROUND_SERVICE`／`FOREGROUND_SERVICE_DATA_SYNC` 保持正在进行的下载，通知显示应用名称、任务数及进度，可取消或返回应用库。Android 13 及以上首次下载时申请 `POST_NOTIFICATIONS`；拒绝后仍受系统的前台服务规则约束。`WAKE_LOCK` 仅在下载服务运行期间以有时限的方式保持 CPU 工作，服务结束即释放。服务不收集额外个人信息，不定期后台扫描应用、不自动安装或重启下载；系统终止后由用户再次发起重试。

## 删除、查询与变更

客户端目前不提供云端个人数据查询或删除入口，因为没有项目服务器上的客户端账号数据。用户可以在系统设置中清除应用数据，在应用内删除下载记录和文件，并在 WebView 或外部服务自身的设置中管理其会话。隐私说明随客户端和源码更新；重大变化会在发布说明中标注。

## 联系方式

隐私问题可以通过项目 [Issues](https://github.com/huarunwin/huarunwin/issues) 反馈。涉及安全漏洞时，请先阅读 [SECURITY.md](../SECURITY.md)，不要在公开 Issue 中发布可利用细节或个人数据。
