# 内容来源与静态镜像

## 设置与行为

设置 → 应用目录 → 内容来源提供三个选项：

| 选择 | 行为 |
| --- | --- |
| 自动（默认） | 首次优先华润赢网站；连接失败、超时、HTTP 429 或 5xx 时尝试另一来源。成功解析后记住该来源，后续优先使用，并在设置中显示最近成功来源。 |
| 华润赢网站 | 固定从 `https://huarun.win/` 获取内容，不自动转向镜像。 |
| GitHub 镜像 | 固定从公开仓库的 Raw 地址获取内容，不自动转向网站。 |

目录、详情及分页 HTML 的每个来源请求最多等待 5 秒，覆盖请求准备、连接、重定向和响应接收；连接与发送阶段各设 3 秒超时。自动模式下发生可切换的错误或达到总时限后，取消当前请求并立即尝试另一来源，不增加等待或重复重试；两个来源都无响应时，网络等待合计约 10 秒，随后显示已有缓存或错误。该时限不包含缓存读取及后续 HTML 解析，也不适用于图片、GitHub Release 版本选择或安装包下载。固定来源同样使用每次 5 秒上限，但不会自动切换。

选择保存在本机。切换后重新加载目录、详情及站内图片，保留导航、搜索、筛选与下载任务。隐藏栏目的旧结果失效，重新进入时按新来源获取。固定来源暂时不可用时，保留该来源可用的缓存并提示重试；没有缓存时显示错误。自动模式将 TLS 握手期间对端断开连接（Dart 的 `Connection terminated during handshake`，无底层 TLS 错误码）视为连接失败并尝试另一来源；404、页面结构异常、证书校验失败及其他 TLS 错误仍不切源，以免把镜像缺页或不可识别的响应掩盖成成功。

GitHub 镜像是一次性静态快照，内容可能晚于网站。选择镜像不会使购买、账号、纠错、第三方下载等在线服务转由 GitHub 提供，也不保证任何网络环境下都可访问。

## 地址与缓存

镜像仓库：[huarunwin/huarunwin-static](https://github.com/huarunwin/huarunwin-static)。未启用 GitHub Pages，客户端通过 HTTP 获取 HTML 原文并使用现有 DOM 解析器，不执行 JavaScript、不新增内容 API 或独立内容 JSON。

| 网站地址 | 镜像请求 |
| --- | --- |
| `https://huarun.win/` | `https://raw.githubusercontent.com/huarunwin/huarunwin-static/main/index.html` |
| `https://huarun.win/apps/flclash` | `https://raw.githubusercontent.com/huarunwin/huarunwin-static/main/apps/flclash.html` |
| `https://huarun.win/jichang` | `https://raw.githubusercontent.com/huarunwin/huarunwin-static/main/jichang.html` |
| 站内图片路径 | 在 Raw 仓库根地址后保留原路径，逐段编码中文与空格。 |

内容模型与解析基准始终使用原网站 URL，保留站内链接、查询参数、锚点及原始下载／购买地址。镜像只改变公开 HTML 和站内图片的传输地址，不把 Raw 地址用于分享、购买、下载、纠错或外部网页访问。外部图片不改写。自动模式的单张站内图片加载失败可再尝试另一来源一次，不修改全局来源偏好。

网站缓存沿用原路径，镜像 HTML 缓存位于内容目录的 `github/` 子目录；内存缓存也包含来源标识。图片按实际请求 URL 缓存。显式切换递增修订号并取消旧请求，异步解析与界面加载检查修订号／代次，旧请求不能回写当前页面。缓存有效期仍为 30 分钟；刷新失败时提示正在展示上次保存的内容。

实现主要位于 `lib/services/content_sources.dart`、`lib/data/repository.dart`、`lib/services/app_controller.dart`、`lib/ui/content_image.dart` 和 `lib/ui/settings.dart`。客户端自身版本更新仍独立读取 `huarunwin-hub`，不随内容来源切换。
