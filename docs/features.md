# 功能与界面

基于 Flutter 3.47.6 的应用目录客户端，从 [huarun.win](https://huarun.win/) 的静态 HTML 读取内容，以适合桌面和手机的 Flutter 页面展示，并提供 Mac 安装助手、Android APK 安装、Windows 系统安装器交接与 Linux AppImage 安装。

## 当前能力

设置中的“关于华润赢”显示实际构建版本，提供“检查更新”和按当前渠道在线读取 Hub 的“更新日志”。启动时自动检查一次；从公开的 `huarunwin-hub/api/updates.json` 读取当前正式或测试渠道，只有该渠道的 `publishedVersion` 高于本机版本才提示。点击“前往下载”后按本机平台和架构在应用内下载，显示进度、取消与重试，完成后衔接更新安装；桌面替换前确认退出，iOS 交接 App Store／TestFlight。测试渠道明确标注测试版本，尚未发布的渠道不提示更新。预先记录的高版本日志不会触发更新，具体格式与发布约束见 [发布与许可](releasing.md) 和 [客户端自身更新](self-updating.md)。

更新提醒参照 FlClash 默认样式，手机和桌面均使用居中浮层：标题与版本分开，日志可选择和滚动，使用连续圆角、中性与主题色胶囊按钮、弹性入场及轻微按压反馈，尊重减少动画设置。独立提供“取消”“本版本不再提示”和“前往下载”；按钮文字放不下时自动上下排列，下载在上、取消在下。“本版本不再提示”只记住当前渠道的这个版本，重启后仍生效；后续新版本继续提醒，手动“检查更新”仍可查看被忽略的更新。点击取消、遮罩、返回或 Esc 仅关闭当次提醒。

- 统一应用目录包含客户端、服务端、订阅工具、规则与配置；支持类型与关键词筛选，客户端另有平台／内核／代码状态／价格组合筛选；综合／最近更新／开源热度／评分数排序。各平台窄屏目录统一使用单列列表，不显示视图切换；宽屏支持网格／列表切换并记住选择。
- App Store 风格详情：窄屏左侧展示大图标，右侧排列名称、类型／内核和单个蓝色实心胶囊按钮；下方横向元信息使用细分隔线，按公开数据展示 Star、评分数及平台等信息。版本与更新日期放在“新功能／版本信息”区，可展开更新说明／介绍，并浏览大图截图与官方渠道；各平台按页面宽度切换布局。
- 所有平台宽度小于 600 dp 时，底部导航依次为发现、应用库、VPS、机场、设置，最后一项直接展示偏好设置；动态与纪事页签暂时隐藏，“全部栏目”入口和总览页面已移除。各主页签按需加载并保留搜索、筛选及滚动位置，离开后停止继续加载分页。应用库为紧接“发现”的独立主页签，桌面侧栏在应用分组后提供同级入口，进行中的任务数量显示在入口；设置移除重复入口，下载目录继续独立设置。应用库首次进入才加载，切换页签和窗口布局保留搜索、筛选、排序及滚动位置；重新进入时核对本机与文件状态，隐藏时停止继续派发版本详情检查。从目录、详情或栏目开始下载均切换到同一个应用库页签的“下载任务”，并清空旧搜索、回到列表顶部。应用、VPS、机场首页移除右上角“更多”和外观菜单及其占位，相关功能统一从设置进入；宽屏手动刷新与详情页操作保留。
- 所有平台窄屏统一采用现有 Android 视觉与交互，按 FlClash 独立实现：中性灰页面、近白大圆角卡片及灰色内层信息区，统一文字层级，应用、VPS 和机场目录的搜索框和筛选按钮分两行独立展示，使用 H Logo 蓝色（`#0071E3`）作为品牌强调色，深色主题使用同色系的较亮颜色以保持对比度。浮动导航的完整胶囊选中态同时包住图标与文字，支持点击及横向拖动预览，松手后切换页签；内容可滚至导航上方，键盘弹出时收起导航。系统状态栏与导航栏透明，滚动内容延伸至状态栏下方；顶部安全间距随内容滚走，初始标题和下拉刷新指示器避开状态栏，横屏仍保留两侧刘海安全区；Mac 窗口按钮继续保留固定避让。浅色、深色和大字号共用同一套层次。
- 窗口缩窄时按实际宽度切换主题、卡片、搜索筛选浮动菜单、排序和导航，保留当前页面、搜索、筛选、已载入内容与滚动位置；变宽后恢复宽屏布局及视图偏好。窄屏筛选入口仅显示选中值，数量旁不显示“已缓存”。下载、安装、重签、授权及原生插件仍按真实系统处理。
- 浅色／深色主题，桌面侧栏与手机底部导航。侧栏用于应用类型与栏目导航，平台筛选统一放在应用列表顶部。主区域的标题、搜索和筛选随卡片一起滚动，导航保持固定。
- 所有页面顶部按钮参照 FlClash 共用圆形／胶囊中性底、24 dp 图标与统一尺寸、间距和按压反馈；填充跟随页面或弹层实际背景，浅深色均保持层次。目录、详情、下载、设置、阅读与许可页通过 `PageHeader` 统一呈现，筛选和图片预览顶部也复用相同控件；Android 及各平台窄屏继续使用下拉刷新。
- 所有页面、平台与窗口宽度均不显示主标题、搜索、筛选和排序区下方的固定说明文案，也不保留对应留白；目录底部和筛选面板同样不重复展示搜索范围、网页载入范围、价格比较规则或排序解释。范围通过搜索框提示和结果数量体现，正文、条目实际信息、加载或错误反馈及操作确认继续保留。
- 桌面侧栏参照 FlClash dev：中性灰窗口底色、紧凑导航行、细品牌色选中指示条与悬停／键盘焦点反馈。可切换 220 dp 展开栏和 80 dp 图标栏并记住偏好；图标悬停显示名称，点击分组会展开侧栏，列表边缘渐隐，底部设置与网站入口固定。
- Steam Deck、路由器与各平台共用“发现应用”顶部的筛选栏，支持触控板／触摸左右滑动及鼠标按住拖动，溢出菜单可直接选择；侧栏及手机栏目不再单列。设备归属按需读取网站公开分类 HTML，与其他条件组合筛选；Steam Deck 不等同于所有 Linux 应用。分类独立缓存并支持失败回退，下载继续按应用明确支持的平台处理。
- HTML 和图片缓存；刷新或解析失败保留可用内容。
- Windows、macOS、Linux 在设置的“下载与安装”分组提供单个“下载目录”入口并显示当前路径，点击进入独立页面；“当前目录”分区独立展示完整路径，支持选择复制和换行，下方“目录操作”分区提供修改、打开和恢复默认操作，“修改目录”行不重复显示当前路径。独立页面使用共用滚动标题和返回按钮，下拉刷新重新读取本机目录偏好；选择目录与恢复默认期间禁用重复操作，取消或失败保留原设置。选择后先确认目录可写，更改只影响新下载和新导入，已有任务、重试及安装继续使用原文件路径。新安装及“恢复默认”统一使用系统“下载”目录下的 `huarunwin` 子目录，已有用户保留原目录；系统未配置下载目录时沿用应用支持目录。Android、iOS 继续使用各自原有目录。
- 应用目录在所有平台及宽度下，有下载状态按钮时只显示这一个操作，移除旁边重复的价格／免费标签及费用分区；宽屏列表、网格和平板卡片保持一致。已下架或无下载入口的条目保留原有状态及查看详情提示。
- 应用详情顶部操作区仅显示左对齐的主按钮，所有平台与宽度均不再附加价格、免费、商店或类型文字及其留白；类型和渠道保留在元信息与官方渠道区域。
- 客户端应用的卡片和详情页共用所有平台的按钮逻辑：未下载的免费应用显示“下载”，有明确金额显示原价格；当前平台已有完成的下载或本机应用时，有可确认的新版本显示“更新”，否则显示“打开”。费用待核实、版本缺失或无法比较时不猜测金额或新版本。已安装且具备可靠启动信息时直接打开应用；只有安装包时打开下载管理继续安装或查看。目录与宽屏详情使用浅灰胶囊底和品牌蓝文字，直接下载和重新下载沿用相同样式，窄屏详情按最新截图改用品牌色实心胶囊与对比文字，深色主题同步适配；长价格可查看完整提示，按钮下方不显示价格或预留空间。选中平台与设备不一致时先弹窗选择平台；详情保留列表的平台选择，“全部”默认当前设备。平台和多架构／包格式弹窗中，点击选项仅切换勾选，点击“确认”才继续，点击“取消”或关闭不下载；缺少安装包时提供官方渠道。
- 按钮根据应用类型与 ID 关联下载记录，兼容旧记录的精确名称。Mac 读取唯一匹配应用包的实际版本及路径；Android 优先通过受管理 APK 包名或安装记录读取当前本机版本，也能按系统返回的真实名称与目录名称／别名唯一匹配通过其他渠道安装的应用，读取实际包名及版本，同名多包不自动选择。Android 本机查询共用快照，首页下拉刷新、下载管理刷新及重新激活后重新检查，不申请全量包查询权限。Linux 已安装 AppImage 使用已记录路径。只为本机应用或已完成下载按需读取公开详情，平台专属版本优先；下载、安装、删除及重新激活后同步按钮状态。Windows／Linux 系统安装器交接不推断安装成功，缺少可靠启动信息时“打开”进入下载管理；iOS 商店／浏览器交接不视为下载完成。更新继续沿用原下载、版本与资源选择及安装验证流程。
- Mac App Store 链接打开系统商店，GitHub 发布页解析出当前 Mac 架构的真实安装包后直接下载。桌面可下载其他平台的安装包并管理进度，异平台文件不提供 Mac 安装操作。
- 桌面及 Android APK 下载支持进度和百分比、取消、重试、删除、历史恢复，最多同时下载 3 个文件，其余排队；排队任务也可取消或删除。拒绝网页响应和不完整文件，有公开 SHA-256 时校验后才保留安装包。删除会清理记录、安装包和临时文件，保留已安装的应用；安装中禁止删除。
- 下载取消或网络中断后，可安全校验的半成品保留供续传，暂时性网络错误最多尝试三次；服务器无法安全续传时重新下载。重启后须主动重试。Android 下载时显示前台服务进度通知，可取消任务或返回应用库；普通切换后台继续下载，移除最近任务、系统停止或强制停止后不承诺继续。首次下载申请通知权限，后台完成不会自动安装。
- 应用库参照 [Komi Store](https://github.com/komi-store/komi-store) 的应用组织方式独立实现，主列表显示紧凑的应用条目，提供全部、可更新、已安装、待安装和下载任务筛选、名称／文件名搜索及更新优先、最近修改和名称排序。进行中的任务优先显示进度，可取消；下载任务中的单个失败任务可重试。已确认的本机应用可打开和检查更新，已下载的新版本文件优先进入安装；多份文件或多种已安装身份由用户进入详情选择。原始包、重签包、改包重签的包名、版本、签名、失败详情和各项文件操作保留在第二级页面。系统安装器交接保留“安装结果待确认”，资源和异平台文件仅作为下载条目显示；下载目录保持独立设置。
- 应用库进入及重新激活时自动核对安装包及本机应用状态：Mac 检查应用路径，Android 检查包名，并匹配当前目录中能唯一确认的本机应用；仅为已确认本机应用读取详情检查版本，最多 4 个并发请求。手动刷新同时重新读取应用目录和对应版本详情。Android 和各平台窄屏可下拉刷新，其他宽屏使用右上角刷新按钮，按钮内显示加载动画。文件丢失后更新可用操作，检查失败保留记录，正在下载或安装的任务继续运行；刷新读取证书摘要供辨认，不验证签名完整性或保证启动能力。
- 导入 APK 按文件实际包名归组并展示真实应用名称，同名不同包名保持独立；各版本、原始包和派生副本仍分别操作。“待安装”逐份核对目标包名、证书和实际版本码，改包／不同签名的副本不会因原版已安装而消失。更新详情刷新失败即使能显示缓存也会提示重试，空的更新列表显示“更新检查未完成”。
- Android 及各平台窄屏的各页面统一使用下拉刷新，移除右上角刷新按钮，包含应用与栏目目录、详情、阅读正文、下载管理、纠错、设置及许可列表和正文。短内容、空列表与失败状态也可下拉；刷新期间保留原内容，失败可重试。设置重新读取本机偏好，内置正文只刷新本地显示，不额外请求网站或重置筛选；纠错页只在网页顶部触发刷新，并等待网页加载结束。
- Android 及各平台窄屏的原生页面与弹层拖动滚动时自动收起键盘，保留搜索文字、筛选和当前页签。
- macOS 下载或导入 DMG／ZIP，验证实际应用和架构，安装到“应用程序”，默认处理本次安装应用的下载隔离属性。显示安装阶段、签名及系统评估信息，失败时可重试或手动安装。
- Android 手机的 APK 下载进入应用内下载管理，点击“安装应用”先检查安装包，再选择安装方式，默认“华润赢安装”；也可选择系统或其他安装器。华润赢使用 PackageInstaller 会话管理进度及结果，保留系统授权与最终确认。支持安装前可选重签、取消后重试、安装成功后打开应用及分享 APK；第三方交接保持结果未确认。iOS 和 Android 上的其他平台下载继续交给系统浏览器。
- Android 覆盖安装前读取 APK 与本机应用的实际版本码，拦截降级并显示双方版本；可取消或重新选择 GitHub 版本／本地 APK，仍允许下载旧版本。原生安装及其他安装器交接前、授权返回后再次核对。安装失败显示具体中文原因，系统错误码与原始说明保存在下载记录的“失败详情”中；不自动卸载、修改版本码或重签绕过限制，APK 保留以便处理。
- Android 可在文件管理器或聊天软件中，通过“打开方式”或“分享”将单文件 APK 交给华润赢。仅接收有读取权限的 content URI，先复制到私有下载目录并保存记录，再打开检查与安装面板；不接管系统默认安装器，系统选择列表中的默认项仍由用户及 Android 决定。
- macOS 支持导入 PKG，交给系统安装器；显示“已交给系统”，安装结果保持未确认。

服务端、订阅工具和规则与配置已合并到“发现应用”。桌面侧栏“应用”分组默认展开，组内提供“全部”以及客户端、服务端、订阅工具、规则与配置四个类型页签，主区域不重复提供类型下拉框；没有侧栏且宽度至少 600 dp 的桌面窗口继续使用下拉框；各平台窄屏在应用目录的浮动菜单中选择类型，选中后直接应用。切换具体应用类型会清除当前的客户端平台、设备、内核、代码状态和价格条件，不覆盖已记住的平台选择；返回“全部”时恢复该选择。桌面“重置筛选”保留当前类型并记住“全部”。导航区域可以独立滚动，设置与网站入口固定。资源的运行环境／运行方式／适配对象保持独立，不当成客户端支持平台。详情展示原始版本含义及官方文档、商店、部署或规则入口，完整指南仍可原生阅读。

全部应用首次默认选中当前设备平台；“平台”筛选菜单将当前平台排在“全部”之后，其余选项保持原有顺序。用户主动选择后，记住平台或设备选项（包括“全部”、Steam Deck 与路由器），下次启动时恢复。设置中的“重置为默认值”清除这项本地记录，立即恢复当前设备平台，外观、网格／列表偏好与下载记录继续保留。

“全部”目录的搜索覆盖已载入的客户端、服务端、订阅工具、规则与配置和所有平台。搜索时暂时收起并停用客户端的平台、设备、内核、代码状态与价格筛选，搜索范围通过搜索框提示体现；清空搜索恢复原浏览筛选，保留已记住的平台与设备偏好。具体类型页的搜索仅覆盖当前类型，客户端页仍应用所选筛选。搜索框按当前类型调整提示，桌面“全部”入口明确列出四类内容。
