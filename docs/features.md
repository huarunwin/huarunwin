# 功能与界面

基于 Flutter 3.47.6 的应用目录客户端，从 [huarun.win](https://huarun.win/) 的静态 HTML 读取内容，以适合桌面和手机的 Flutter 页面展示，并提供 Mac 安装助手、Android APK 安装、Windows 系统安装器交接与 Linux AppImage 安装。

## 当前能力

Android 设置首页依次为外观、应用目录、帮助与反馈、版本信息、关于华润赢和高级设置，桌面同样保留下载目录；iOS 不展示没有下载目录入口的“应用目录”分组。“帮助与反馈”分组位于版本信息上方，依次展示反馈、Telegram 群组和 Telegram 频道；版本信息继续显示实际构建版本，提供“检查更新”和按当前渠道在线读取 Hub 的“更新日志”。关于与高级设置位于底部，首页不展示网络分组、来源选项或当前线路，需要手动选择来源时进入“高级设置 → 内容来源”。首页分组底部间距为 16 dp，其他页面保持原有间距。独立关于页按“隐私与许可”“网站说明”“网站”分组，客户端隐私与软件许可保留离线阅读，网站隐私单独标明，访问网站保留于此；社区入口集中在设置首页。关于页沿用共用滚动标题、返回、安全区与下拉刷新，普通刷新只重新呈现本地内容。

启动时自动检查一次；从公开的 `huarunwin-hub/api/updates.json` 读取当前正式或测试渠道，只有该渠道的 `publishedVersion` 高于本机版本才提示。点击“前往下载”后按本机平台和架构在应用内下载，显示进度、取消与重试，完成后衔接更新安装；桌面替换前确认退出，iOS 交接 App Store／TestFlight。测试渠道明确标注测试版本，尚未发布的渠道不提示更新。预先记录的高版本日志不会触发更新，具体格式与发布约束见 [发布与许可](releasing.md) 和 [客户端自身更新](self-updating.md)。

更新提醒参照 FlClash 默认样式，手机和桌面均使用居中浮层：标题与版本分开，日志可选择和滚动，使用连续圆角、中性与主题色胶囊按钮、弹性入场及轻微按压反馈，尊重减少动画设置。独立提供“取消”“本版本不再提示”和“前往下载”；按钮文字放不下时自动上下排列，下载在上、取消在下。“本版本不再提示”只记住当前渠道的这个版本，重启后仍生效；后续新版本继续提醒，手动“检查更新”仍可查看被忽略的更新。点击取消、遮罩、返回或 Esc 仅关闭当次提醒。

- 统一应用目录包含客户端、服务端、订阅工具、规则与配置；支持类型与关键词筛选，客户端另有平台／内核／代码状态／价格组合筛选；综合／最近更新／开源热度／评分数排序。窄屏首页与宽屏全部目录的主标题统一为“发现”，与导航入口一致；宽屏具体应用类型页保留类型名称。各平台窄屏目录统一使用单列列表，不显示视图切换；宽屏支持网格／列表切换并记住选择。
- App Store 风格详情：窄屏左侧展示大图标，右侧排列名称、类型／内核和单个蓝色实心胶囊按钮；下方横向元信息使用细分隔线，按公开数据展示 Star、评分数及平台等信息。元信息栏后依次展示截图预览、“新功能／版本信息”和应用介绍；版本与更新日期放在“新功能／版本信息”区，可展开更新说明／介绍，并浏览大图截图与官方渠道；各平台按页面宽度切换布局，正文分区顺序一致。截图在所有平台均直接展示，不显示“预览”标题、标题占位及截图上方的元信息栏底线；元信息栏顶部及内部竖分隔线保留，无截图时沿用原有边线。截图通过横向滚动浏览、点击放大，不展示左右切换按钮。
- 所有平台宽度小于 600 dp 时，底部导航依次为发现、应用库、VPS、机场、设置，最后一项直接展示偏好设置；动态与纪事页签暂时隐藏，“全部栏目”入口和总览页面已移除。各主页签按需加载并保留搜索、筛选及滚动位置，离开后停止继续加载分页。应用库为紧接“发现”的独立主页签，桌面侧栏在“发现”分组后提供同级入口，进行中的任务数量显示在入口；设置移除重复入口，下载目录继续独立设置。应用库首次进入才加载，切换页签和窗口布局保留搜索、筛选、排序及滚动位置；重新进入时核对本机与文件状态，隐藏时停止继续派发版本详情检查。从目录、详情或栏目开始下载均切换到同一个应用库页签的“下载任务”，并清空旧搜索、回到列表顶部。应用、VPS、机场首页移除右上角“更多”和外观菜单及其占位，相关功能统一从设置进入；宽屏手动刷新与详情页操作保留。
- 所有平台窄屏统一采用现有 Android 视觉与交互，按 FlClash 独立实现：中性灰页面、近白大圆角卡片及灰色内层信息区，统一文字层级，应用、VPS 和机场目录的搜索框和筛选按钮分两行独立展示，使用 H Logo 蓝色（`#0071E3`）作为品牌强调色，深色主题使用同色系的较亮颜色以保持对比度。浮动导航的完整胶囊选中态同时包住图标与文字，支持点击及横向拖动预览，松手后切换页签；内容可滚至导航上方，键盘弹出时收起导航。系统状态栏与导航栏透明，滚动内容延伸至状态栏下方；顶部安全间距随内容滚走，初始标题和下拉刷新指示器避开状态栏，横屏仍保留两侧刘海安全区；Mac 窗口按钮继续保留固定避让。浅色、深色和大字号共用同一套层次。
- 窗口缩窄时按实际宽度切换主题、卡片、搜索筛选浮动菜单、排序和导航，保留当前页面、搜索、筛选、已载入内容与滚动位置；变宽后恢复宽屏布局及视图偏好。窄屏筛选入口仅显示选中值，数量旁不显示“已缓存”。下载、安装、重签、授权及原生插件仍按真实系统处理。
- 浅色／深色主题，桌面在宽度达到 900 dp 时使用侧栏，较窄窗口与手机使用底部导航。桌面没有侧栏时，底部始终提供发现、应用库、VPS、机场和设置五项，600–899 dp 不减少页签；非窄屏 iOS 保留原有三项导航。侧栏用于应用类型与栏目导航，平台筛选统一放在应用列表顶部。主区域的标题、搜索和筛选随卡片一起滚动，导航保持固定。
- 所有页面顶部按钮参照 FlClash 共用圆形／胶囊中性底、24 dp 图标与统一尺寸、间距和按压反馈；填充跟随页面或弹层实际背景，浅深色均保持层次。目录、详情、下载、设置、阅读与许可页通过 `PageHeader` 统一呈现，标题行无论是否有操作按钮均至少 48 dp 高，大字号或标题换行时自然增高，避免应用库加号使下方搜索框相对其他窄屏页签下移。筛选和图片预览顶部也复用相同按钮控件；Android 及各平台窄屏继续使用下拉刷新。
- 应用库顶部与应用首页共用标题、`CatalogSearchField` 胶囊搜索框及筛选／排序菜单，搜索、状态筛选、排序与数量依次分行，窄屏相邻控件行间距为 12 dp。状态菜单保留全部、可更新、已安装、待安装和下载任务及各自数量；默认入口显示“状态”，选择具体状态后显示该值。排序保留更新优先、最近修改和名称，结果数量使用共用样式靠右，空间不足时换行；导入安装包及原有刷新、搜索和状态保留行为不变。
- 所有页面、平台与窗口宽度均不显示主标题、搜索、筛选和排序区下方的固定说明文案，也不保留对应留白；目录底部和筛选面板同样不重复展示搜索范围、网页载入范围、价格比较规则或排序解释。范围通过搜索框提示和结果数量体现，正文、条目实际信息、加载或错误反馈及操作确认继续保留。
- 桌面侧栏参照 FlClash dev：中性灰窗口底色、紧凑导航行、细品牌色选中指示条与悬停／键盘焦点反馈。可切换 220 dp 展开栏和 80 dp 图标栏并记住偏好；图标悬停显示名称，点击分组会展开侧栏，列表边缘渐隐，底部设置与网站入口固定。
- Steam Deck、路由器与各平台共用“发现应用”顶部的筛选栏，支持触控板／触摸左右滑动及鼠标按住拖动，溢出菜单可直接选择；侧栏及手机栏目不再单列。设备归属按需读取网站公开分类 HTML，与其他条件组合筛选；Steam Deck 不等同于所有 Linux 应用。分类独立缓存并支持失败回退，下载继续按应用明确支持的平台处理。
- HTML 和图片缓存；刷新或解析失败保留可用内容。
- 应用详情在“应用介绍”下方展示“相关链接”：按官网、GitHub、TG 群组、TG 频道排列，使用对应图标及中性灰胶囊，左对齐并按可用空间自动换行。同类多个入口保留网页原标签区分，悬停显示原始链接；只显示网页实际提供的应用专属入口，缺失时隐藏按钮或整个分区，点击由系统打开原始地址；已放入本区的地址不在“官方渠道”重复展示。
- 设置 → 高级设置 → 内容来源统一提供“自动／华润赢网站／GitHub 镜像／GH-Proxy／jsDelivr 镜像”，不再另设加速选择。GitHub 镜像固定直连，GH-Proxy 固定通过代理读取镜像内容和图片，并分别控制应用内 GitHub 文件的连接方式。默认自动，首次依次尝试网站、GitHub Raw 直连、GH-Proxy、jsDelivr，连接失败时尝试下一来源。回退后优先使用成功来源 2 小时，持续浏览不延长保持时间，重启后保留剩余时间；到期后的下一次联网加载重新从网站开始，手动刷新立即重试网站。当前来源失败仍可切换，固定来源不自动切换。自动模式显示最近成功来源，选择保存在本机，切换后重新加载内容及站内图片。两个镜像读取同一份一次性快照，可能晚于网站更新，jsDelivr 另有 CDN 缓存；下载、购买、纠错及分享继续使用原始链接，详见 [内容来源与静态镜像](content-sources.md)。
- Android、Windows、macOS、Linux 在设置的“应用目录”分组中只提供单个“下载目录”入口，入口不显示具体路径或目录 URI，点击进入独立页面；不再单列“下载与安装”分组。页面使用“当前下载目录”“修改目录”“恢复默认”，沿用共用滚动标题、返回与本机偏好刷新。桌面独立显示可选择复制、换行的完整路径，另提供打开目录；修改仅影响新下载和新导入，取消不保存，旧文件保留原位置。桌面默认使用系统下载目录下的 `HuaRunWin Downloads`，回退规则见[数据与结构](architecture.md)。Android 同样提供“打开目录”，将当前自选文件夹交给文件管理器；不再跳转应用库。默认应用专用目录通过只读文档接口在文件管理器中展示当前下载文件，不要求改用公共目录；历史记录、临时文件和其他私有数据不展示。授权失效或没有可用文件管理器时明确说明原因，不改开其他位置，也不修改保存目录。应用专用目录按外部 `files/Download`、外部 `files/downloads`、内部 `files/downloads` 顺序选用，兼容原有存储偏好，不再向用户提供内部／外部切换。iOS 继续使用原有应用目录下的 `downloads`。
- Android 的“当前下载目录”显示实际完整位置，支持选择复制和换行；未选择自定义文件夹时显示当前受管理目录的完整路径。自选本机文件夹按系统存储卷信息显示完整路径，无法确认本地路径的文档提供方显示完整目录 URI。“修改目录”直接打开系统文件夹选择器，Android 8.0 及以上优先定位当前自选文件夹；默认应用专用位置不向系统选择器开放，因此从系统“下载”目录开始，失效目录由系统回退，旧系统沿用选择器默认位置。具体位置仅在独立下载目录页展示，恢复默认确认框显示真实默认路径。原始 APK 下载完成后自动保存副本，不再另设保存副本分组或自动保存开关；页面底部用一句话说明复制行为及安装文件仍由应用管理。“恢复默认”停用并清除自选目录，恢复应用管理的默认位置，已有文件保留。已有下载、导入包和重签派生包不自动复制；选有自定义目录时，原始包卡片仍提供手动保存、取消与失败重试。相同内容复用，同名不同内容自动编号，副本失败不影响原文件安装。恢复默认、切换文件夹、删除应用内文件或卸载客户端不主动删除已完成共享副本；应用专用文件仍受系统卸载清理规则约束。
- 应用目录在所有平台及宽度下，有下载状态按钮时只显示这一个操作，移除旁边重复的价格／免费标签及费用分区；宽屏列表、网格和平板卡片保持一致。已下架或无下载入口的条目保留原有状态及查看详情提示。
- 应用详情顶部操作区仅显示左对齐的主按钮，所有平台与宽度均不再附加价格、免费、商店或类型文字及其留白；类型和渠道保留在元信息与官方渠道区域。
- 客户端应用的卡片和详情页共用所有平台的按钮逻辑：未下载的免费应用显示“下载”，有明确金额显示原价格；当前平台已有完成的下载或本机应用时，有可确认的新版本显示“更新”，否则显示“打开”。费用待核实、版本缺失或无法比较时不猜测金额或新版本。已安装且具备可靠启动信息时直接打开应用；只有安装包时打开下载管理继续安装或查看。目录与宽屏详情使用浅灰胶囊底和品牌蓝文字，直接下载和重新下载沿用相同样式，窄屏详情按最新截图改用品牌色实心胶囊与对比文字，深色主题同步适配；长价格可查看完整提示，按钮下方不显示价格或预留空间。选中平台与设备不一致时先弹窗选择平台；详情保留列表的平台选择，“全部”默认当前设备。平台和多架构／包格式弹窗中，点击选项仅切换勾选，点击“确认”才继续，点击“取消”或关闭不下载；缺少安装包时提供官方渠道。
- 按钮根据应用类型与 ID 关联下载记录，兼容旧记录的精确名称。Mac 读取应用包的实际版本与路径；Android 优先通过受管理 APK 或安装记录的包名读取当前本机版本，也能按真实名称／别名匹配其他渠道安装的可启动应用，不申请全量包查询权限。Windows 读取系统卸载注册项，Linux 读取发行版软件包数据库及已记录的 AppImage；目录名称／别名须与本机名称精确匹配，多个身份不自动选择。查询共用快照，刷新及重新激活后重新核对。只为已确认本机应用或已完成下载按需读取公开详情，缺少可靠启动信息的本机应用显示“已安装”，应用库中提供管理操作。系统安装器、商店或浏览器交接不推断成功；更新仍复用原下载、版本与资源选择及安装验证。
- Mac App Store 链接打开系统商店，GitHub 发布页解析出当前 Mac 架构的真实安装包后直接下载。桌面可下载其他平台的安装包并管理进度，异平台文件不提供 Mac 安装操作。
- 桌面及 Android APK 下载支持进度和百分比、取消、重试、删除、历史恢复，最多同时下载 3 个文件，其余排队；排队任务也可取消或删除。拒绝网页响应和不完整文件，有公开 SHA-256 时校验后才保留安装包。删除会清理记录、安装包和临时文件，保留已安装的应用；安装中禁止删除。
- 下载取消或网络中断后，可安全校验的半成品保留供续传，暂时性网络错误最多尝试三次；服务器无法安全续传时重新下载。重启后须主动重试。Android 下载时显示前台服务进度通知，可取消任务或返回应用库；普通切换后台继续下载，移除最近任务、系统停止或强制停止后不承诺继续。首次下载申请通知权限，后台完成不会自动安装。
- 应用库参照 [Komi Store](https://github.com/komi-store/komi-store) 的应用组织方式独立实现，主列表显示紧凑的应用条目，提供全部、可更新、已安装、待安装和下载任务筛选、名称／文件名搜索及更新优先、最近修改和名称排序。进行中的任务优先显示进度，可取消；下载任务中的单个失败任务可重试。点击应用统一进入“应用管理”，上方展示本机版本、公开版本及更新状态，下方展示安装包与资源；没有本地安装包也保留已确认的本机信息和可用操作。匹配目录的应用提供“检查更新”和次要入口“查看应用介绍”。列表继续提供打开、更新、安装等快捷操作；多份文件或多个已安装身份在管理页明确选择，每个身份单独提供打开入口。原始包、重签包、改包重签的包名、版本、签名、失败详情和各项文件操作继续保留。系统安装器交接保留“安装结果待确认”，资源和异平台文件仅作为下载条目显示；下载目录保持独立设置。

桌面机场详情收紧头部，公开套餐数量与付款周期在空间足够时集中展示于标题右侧，较窄窗口或大字号时移至头部下方，不再平分整页宽度；缺少独立身份时省略重复的“机场”类别。套餐区复用网页明示的付款周期筛选，使用“全部／月付／年付／半年付”等实际标签；套餐保留网页顺序，宽屏双列、空间不足时单列，使用机场目录同款的中性页面底色和近白无描边卡片，连续圆角、20 dp 内边距及卡片间距均沿用目录。套餐名位于顶部，流量、速度和设备数复用目录规格列，缺项保留列位，价格放在底部；详情规格允许完整换行。筛选隐藏的套餐仍保留原始锚点，跳转时恢复全部。价格与机场目录共用正文色金额和小字号币种／周期样式，币种居中、付款周期沿金额底部基线对齐，原金额与付款周期完整保留，不添加折算月价。

机场详情的 TG 群组与频道作为顶部次要操作，放在购买按钮旁并按空间自动换行；只展示页面社区区域公开的 Telegram 链接，沿用原始地址。正文不重复展示已上移的入口，其他联系信息保留。频道近况移至头部下方、套餐上方，使用中性公告卡片，默认展示两行原文预览，点击展开或收起完整内容；保留原文、阅读目录和锚点，没有近况内容时不显示占位。

Android 的机场与 VPS 目录、详情继续原生展示，仅购买、访问网站及“查看网页”入口改为应用内 WebView；站内详情、分类、分页和锚点仍使用原有路由。网页容器保留返回、下拉刷新及失败重试，网页内 HTTP／HTTPS 导航继续在应用内加载。购买链接完整保留网站原有地址、查询参数与锚点；机场仍通过 `/jichang/{id}/buy` 跳转，不改写为详情页。客户端不代购，也不根据名称构造供应商或安装包地址。

**交互边界：**纠错网页及其登录、提交交互、Android 的 VPS 与机场购买、访问网站链接及其网页内导航留在应用内 WebView，其他网站专有在线交互仍通过系统浏览器完成。macOS、Android 和 iOS 使用 `webview_flutter`；Windows 使用 WebView2（`webview_flutter_windows`），支持表单输入、刷新、失败重试、滚动标题与主题同步，缺少运行时时提示安装网页组件。Linux 暂未接入应用内 WebView，显示不可用说明，不自动外跳。目录原生筛选只使用 HTML 明示的数据；网站 JS 额外数据文件中的维度（例如未显示在卡片上的网络分类、部分库存／周期组合、TG 人数排序、协议场景关联）不作推断，也未宣称与网站 JS 筛选完全一致。原生阅读页面保留相关正文、全部可见套餐与来源，页面菜单可打开网站执行其专有交互。后台管理 `/master` 不属于客户端公开功能。

优先验证 macOS。Android、iOS、Windows、Linux 平台工程已生成，工程存在不代表全部平台已验收。暂不支持 Web 构建。
