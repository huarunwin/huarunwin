## 文档维护

- README 作为源码公开项目入口，只保留简介、主要功能、下载、快速开始、反馈与许可等必要信息；项目授权以根目录 [LICENSE](../LICENSE) 为准。
- 开发说明、架构设计、实现方案、调研结论、平台限制、发布操作和验证记录统一存放在 `docs/`；后续必要文档也放在这里。
- 优先更新对应主题的已有文档；新增主题时使用含义明确的文件名，并更新本索引。
- 产品与开发约束保留在 [AGENTS.md](../AGENTS.md)，按任务需要从本索引读取详细说明。
- 历史验证保留日期、版本背景、实际执行范围及未覆盖事项，不把旧记录当作最新验证结论；仅在实际执行检查后记录结果。
- 文中的命令和源码路径默认以仓库根目录为基准，Markdown 相对链接以所在文件为基准。
